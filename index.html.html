如何免費取得 Google Client ID？（只需設定一次）
  1. 前往 Google Cloud Console 建立新專案，搜尋並啟用 Google Drive API。
  2. 左側選單點選「OAuth 同意畫面」➔ 選「外部 (External)」➔ 填入應用程式名稱並將您自己的 Gmail 加入「測試使用者」。
  3. 左側選單點選「憑證」➔「建立憑證」➔「OAuth 用戶端 ID」➔ 類型選「網頁應用程式」。
  4. 在「已授權的 JavaScript 來源」新增您放置此網頁的網址（例如 https://您的帳號.github.io 或 http://localhost:8080），建立後複製 Client ID 貼到上方即可。
